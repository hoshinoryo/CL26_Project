追加した機能

1.追加したアイテム
Potion：HPが30回復します。
Sword:プレイヤーの攻撃力が10増加します。
Coin：スコアが100増加します。また、マーケットでPotionまたはSwordを購入するために使用できます。

2.Inventoryの構造
GameInventoryItemは、アイテム1種類分の情報を保持します。
GameInventoryクラスでは、listを使用してアイテムを管理しています。

3.アイテムのドロップと取得
敵のHPが0になると、Potion、Sword、Coinのいずれかをランダムでドロップします。プレイヤーとフィールド上のアイテムの当たり判定が重なると、そのアイテムを取得します。
取得時には以下の処理を行います：
アイテムをInventoryに追加
アイテムの効果をプレイヤーに適用
フィールド上のアイテムを削除

4.algorithmとラムダ式の使用
AddItem()、GetItemCount()、RemoveItem()でtd::find_ifとラムダ式を使用して指定された種類を検索します。

5.Round機能
GameRoundManagerクラスで現在のRoundとRoundごとに敵の生成数を管理しています。各生成点は規定数の敵を生成すると停止します。
Roundは現在全部で3つです。ROUND 1とROUND 2の終了後はメニューを表示し、次のROUNDまたはマーケットを選択できます。ROUND 3をクリアするとGAME CLEARになります。

6.マーケット機能
各Roundの間に表示されるメニューからマーケットを選択すると、Market画面へ移動します。マーケットにはPotionとSwordを購入できます。
購入回数に制限はありません。Coinを所持している限り、同じアイテムを繰り返し購入できますが、Coinが不足している場合は購入できず、Not enough Coinsと表示されます。
